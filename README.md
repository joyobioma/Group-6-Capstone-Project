## Group-6-Capstone-Project — Planets Fact Site
Capstone Project for TS Academy Hajime Cohort - Group 6.
A responsive planet fact site built from Figma design that fetches live planet data from API.

### Project Overview 
This project is a responsive planet fact site that provides information about the planets in our solar system.

It is based on the provided Figma design and developed using HTML, CSS, and JavaScript. The site fetches planet data from an API and displays information such as the planet's name, image, type, distance from the Sun, mass, diameter, temperature, gravity, moons, and other details.

The project also includes interactive features and responsive design so that it works well across different screen sizes.

### How To Run The Project Locally

1. Clone the repository from GitHub.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension if it is not already installed.
4. Open the index.html file.
5. Right-click the file and select Open with Live Server.
6. The website will open in your browser.

An internet connection is required to retrieve planet data from the external API.
